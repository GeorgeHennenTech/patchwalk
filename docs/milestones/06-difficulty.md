# M6 — Difficulty toggle

## Facts
- One fact graph, three renderings: beginner (exact values, one concept per step), intermediate (ranges and ear
  targets), advanced (goal-only, values on request).

## Acceptance
- Toggling never changes which facts exist or their order, only grouping and wording (tested).
- Beginner splits multi-concept steps; advanced hides values behind a reveal.
- Intermediate ranges are computed by code from the exact value, and the validator accepts only those ranges.
