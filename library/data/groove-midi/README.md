# Groove MIDI Dataset (MIDI only), version 1.0.0

Real drummers playing on an electronic kit, recorded as MIDI: 1,150 MIDI files, about 13.6 hours, with
`info.csv` naming each file's drummer, style, tempo, time signature and whether it is a beat or a fill.

- Made by Gillick, Roberts, Engel, Eck and Bamman (Google Magenta), "Learning to Groove with Inverse Sequence
  Transformations", ICML 2019. https://magenta.tensorflow.org/datasets/groove
- Licence: Creative Commons Attribution 4.0 International (the `LICENSE` file inside the zip). Use is allowed
  with credit: **any lesson, pattern or figure made from it must credit the dataset and its authors.**
- Supplied by the owner on 20 Nov 2026 as the publisher's own zip, kept here unopened.

What it is for: real timing and loudness (how far off the grid, how hard) for lessons on feel and groove.
It is data, not a text: the guide does not search it. Nothing has been built from it yet.
