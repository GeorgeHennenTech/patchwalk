## You will be able to
Place an oscillator in a register and offset it by a musical interval or a few cents.

## Hear it first
One key played three ways: as is, an octave down, and with a fifth added on top.

## The idea
Three controls move an oscillator relative to the key you press. Octave moves it in doublings. Semitone moves it in keyboard steps, twelve to the octave. Fine moves it in cents, a hundred to the semitone, which is too small to hear as a new note.

## Steps
| Do | On screen | Check | You should hear |
|---|---|---|---|
| Hold a middle note and set Octave to -1. | Octave control | Octave is -1 | The same note, lower |
| Set Octave to -2. | Same | Octave is -2 | Bass register |
| Return Octave to 0 and set Semitone to +7. | Semitone control | Octave 0, semitone +7 | A different note: a fifth above the key |
| Set Semitone back to 0 and move Fine to +20 cents. | Fine control | Semitone 0, fine 15 to 25 | Barely any change |
| Reset Fine. | Same | Fine is 0 | No change you can name |

## Ear check
Two notes: an octave apart, a fifth apart, or the same? Then: did the pitch move by a semitone or by a few cents?

## In Serum
Start from Init and set Osc A one octave down. Save and drop it: the app checks the stored octave.

In the guide: pitch controls, p. 40. The controls are labelled OCT (octave), SEM (semitone), FIN (fine, in cents) and CRS (continuous, no snapping).

## Recap
- Octave sets register.
- Semitones make intervals.
- Fine tune only matters next to another sound.

## Guide notes
Comment on register: two octaves down is bass territory, and say so. The inaudibility of fine tune is the point; it sets up lesson C1.5.
