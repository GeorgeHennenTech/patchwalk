## You will be able to
Make sound on the practice synth with the mouse, the computer keyboard or a MIDI keyboard, and hold a note while you adjust something.

## Hear it first
A single held note, then a short four-note phrase, both on the starting patch.

## The idea
Everything in this course is learned by changing one thing while a note sounds. So the first skill is simply getting a note to play and stay playing. The starting patch is deliberately plain: one steady tone that starts and stops instantly.

## Steps
| Do | On screen | Check | You should hear |
|---|---|---|---|
| Click "Start audio". | Start button | Audio is running | Nothing yet |
| Click any key on the on-screen keyboard. | Keyboard | A note was played | A plain, bright tone |
| Play a note from your computer keyboard (the home row). | Key map overlay | A note came from the keyboard | The same tone at a different pitch |
| Press "Hold" and play a note. | Hold button | A note is latched | A note that keeps sounding |
| Turn the volume down to a comfortable level, then release Hold. | Volume | Volume changed; no notes held | The note getting quieter, then silence |

## Ear check
None. This lesson only checks that you can play.

## In Serum
Load the Init preset and play a few notes. Save it untouched and drop it in: the app confirms nothing differs from Init.

## Recap
- Audio starts only after you click.
- Hold keeps a note sounding so your hands are free.
- The starting patch is one plain tone; every lesson changes it from there.

## Guide notes
If no sound: check the browser tab is not muted and the device volume is up before anything else. Comment on which input the learner used and mention the other two exist. Encourage a low listening level from the start.
