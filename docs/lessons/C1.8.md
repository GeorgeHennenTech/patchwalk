## You will be able to
Explain why the same note can start differently each time, and choose fixed or random phase on purpose.

## Hear it first
The same note struck eight times with random phase, then eight times with fixed phase.

## The idea
Phase is where in its cycle a wave starts. With fixed phase every note begins identically, which is tight and repeatable. With random phase each note begins somewhere different, which sounds more natural but varies. When two oscillators are layered, their relative phase also decides whether they add or partly cancel at the start.

## Steps
| Do | On screen | Check | You should hear |
|---|---|---|---|
| Set phase to fixed and strike one note repeatedly. | Phase control, random amount, a scope that freezes at note start | Random at 0; six notes played | Identical starts |
| Raise Random to full and strike again. | Same | Random at maximum; six notes played | Slightly different starts |
| With two identical oscillators and fixed phase, move one oscillator's phase to the opposite point. | Second oscillator's phase | Phases half a cycle apart | The sound nearly vanishing |
| Bring the phase back. | Same | Phases equal | Full level again |
| Choose fixed phase for a bass sound. | Same | Random at 0 | Every note hitting the same way |

## Ear check
Are these repeated notes identical or varying?

## Recap
- Phase is where the cycle starts.
- Fixed is consistent; random is natural.
- Opposite phases cancel.

## Guide notes
Cancellation at opposite phase only works when both oscillators are otherwise identical; if it does not vanish, check shape, pitch and level match.
